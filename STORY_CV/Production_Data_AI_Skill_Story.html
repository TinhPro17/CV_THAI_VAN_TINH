04 · SUPPORTING SKILL

생산관리 · 데이터 · AI 자동화

Production Management · Data · AI Automation

ChatGPT/AI, Google Workspace, Google Sheets, n8n, Firebase 등을 활용하여 개인 업무의 데이터 정리, 저장, 자동화 및 보고 흐름을 구성해 본 경험이 있습니다. 아직 제조현장에 직접 적용한 경험은 없지만, 향후 생산현장의 반복 업무와 보고 과정을 더 효율적으로 만드는 데 활용하고 싶습니다.

01. 직접 사용한 도구와 경험

ChatGPT / AI기술 학습, 문제 정리, 문서 작성, 정보 요약 및 작업 흐름 설계에 지속적으로 활용하고 있습니다.
Google WorkspaceGoogle Sheets 등을 활용하여 정보를 정리하고, 데이터 기반의 문서 및 보고 구조를 만드는 연습을 해왔습니다.
n8n개인 자동화 workflow를 구성하고, 입력된 데이터를 다른 서비스로 전달·저장하는 흐름을 실습했습니다.
Firebase / Firestore개인 프로젝트에서 데이터를 저장하고 관리하는 구조를 사용해 본 경험이 있습니다.
AI Agent / 자동화AI Agent와 자동화 도구를 활용하여 반복적인 디지털 업무를 줄이는 방법을 개인적으로 학습하고 실습해 왔습니다.

02. 개인 자동화 프로젝트 경험

현재까지 제조현장의 생산관리 시스템을 직접 구축한 경험은 없습니다. 다만 개인 프로젝트에서 입력 → 데이터 처리 → 저장 → 결과 확인의 기본 자동화 흐름을 직접 구성한 경험이 있습니다.

사용자 입력→자동 처리→데이터 저장→정리 / 보고

이러한 구조는 제조현장의 생산량, 불량, 설비 이상, 정지시간 등의 정보를 기록하고 정리하는 업무에도 적용할 수 있다고 생각합니다.

※ 현재는 개인 프로젝트 및 학습 경험이며, 실제 생산관리 시스템을 운영한 경력은 아닙니다.

03. 현재 기술 수준

직접 사용

ChatGPT/AI · Google Workspace · Google Sheets · n8n · Firebase/Firestore · 개인 자동화 workflow

적용 가능 영역

데이터 입력 · 저장 · 정리 · 반복업무 자동화 · 보고 흐름 · 알림 · 기본적인 데이터 관리

향후 학습

PLC/CNC/사출기/로봇 데이터 직접 수집 · 산업용 API · OPC UA · MTConnect · Modbus · 실제 스마트팩토리 데이터 연동

현재 수준

저는 IT 엔지니어나 생산관리 시스템 개발자가 아니라, 생산현장을 이해하면서 디지털 도구를 보조적으로 활용하려는 단계입니다. 실제 제조현장에 적용하려면 회사의 데이터 구조와 작업방식을 먼저 이해해야 한다고 생각합니다.

04. 제조현장에서 활용할 수 있는 방향

생산보고 자동화

생산량, 불량, 정지시간 등을 입력하면 일/주/월 단위로 자동 정리하여 보고하는 구조

설비 이상 이력관리

어떤 설비에서 어떤 문제가 언제 발생했는지 기록하고 반복되는 이상을 추적하는 구조

품질 데이터 정리

불량 수량과 유형을 정리하고 제품·설비·작업별로 비교할 수 있는 데이터 관리

자동 알림

보고 누락, 장시간 정지, 특정 조건 발생 시 메신저 또는 이메일로 알림을 보내는 구조

현장 Dashboard

생산량, 불량, 설비 상태 등 주요 정보를 한 화면에서 확인할 수 있도록 정리하는 구조

AI 보고 지원

수집된 데이터를 AI가 요약하여 관리자가 확인해야 할 주요 내용을 빠르게 정리하는 방식
